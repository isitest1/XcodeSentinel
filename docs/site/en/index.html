Install in 3 Steps

1

Download the DMG

Grab the latest .dmg from GitHub Releases. Double-click to mount it.

2

Drag to Applications

Drag XcodeSentinel to your Applications folder. Launch it — it lives in the menu bar with no Dock icon.

3

Grant Accessibility permission

On first run it opens System Settings → Privacy → Accessibility. Enable it there. No Screen Recording permission needed.
