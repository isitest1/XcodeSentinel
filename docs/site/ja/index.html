主な機能

スクリーンショット

スクリーンショットは最初のタグ付きリリース時に追加します。

3 ステップでインストール

1

DMG をダウンロード

GitHub Releases から最新の .dmg を取得し、ダブルクリックしてマウントします。

2

Applications にドラッグ

XcodeSentinel を Applications フォルダにドラッグ。起動するとメニューバーに常駐します（Dock アイコンなし）。

3

アクセシビリティ権限を許可

初回起動時にシステム設定 → プライバシー → アクセシビリティが開きます。XcodeSentinel を有効にします。画面収録権限は不要です。
